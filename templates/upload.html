Requirements & Guidelines

File Requirements

  • File format: CSV only
  • Must contain a column named 'review'
  • Maximum file size: 10MB
  • Reviews should be in text format

Best Practices

  • Use clear, readable text for better accuracy
  • Include a variety of review lengths
  • Ensure reviews are in English for best results
  • Remove any special characters that might interfere

Processing Time

Analysis time depends on the number of reviews:
• < 100 reviews: ~10-30 seconds
• 100-500 reviews: ~30-60 seconds
• 500+ reviews: ~1-3 minutes

Example CSV Format

Your CSV should look like this:

review rating date
"This product exceeded my expectations!" 5 2024-01-15
"Disappointed with the quality" 2 2024-01-16
"Good value for the price" 4 2024-01-17

The 'review' column is required. Additional columns like 'rating' and 'date' are optional and will be preserved in the output.
